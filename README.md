# Апельсин — контент-планер

Рабочее русскоязычное веб-приложение для преподавателя английского языка, который ведёт несколько социальных сетей. В локальном демо-режиме никакая регистрация не нужна: данные сохраняются в браузере. Для синхронизации между устройствами подготовлены Supabase-клиент, схема и Row Level Security.

## Быстрый запуск

Понадобится Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Вверху должна быть надпись «Демонстрационный режим: данные сохраняются только в этом браузере».

## Что работает

- Главная: сводка, ближайшие публикации, предупреждения, лучший материал, контент-баланс.
- Календарь: месяц/неделя, поиск, фильтр площадок, создание на дату, перенос drag-and-drop, открытие карточки.
- Доска: семь этапов, поиск и перенос карточек между колонками с автосохранением статуса.
- Банк идей: создание, редактирование, копирование, удаление и превращение идеи в материал с версиями для выбранных соцсетей.
- Карточка контента: все основные поля и любое количество адаптированных версий для площадок.
- Аналитика: ручной ввод показателей, вычисление вовлечённости и конверсий, фильтры, графики и рейтинг публикаций.
- Настройки: площадки и цвета, рубрики, форматы, контент-баланс, часовой пояс и уведомления.
- Экспорт календаря и аналитики в CSV, полная резервная копия в JSON и импорт JSON с предварительным предупреждением.
- Адаптивный интерфейс и клавиатурные состояния фокуса.

## Подключение Supabase

1. Создайте бесплатный проект на Supabase.
2. Откройте SQL Editor и выполните файл `supabase/migrations/001_initial_schema.sql`.
3. В Authentication настройте желаемый способ входа, например Email/Password.
4. Скопируйте `.env.example` в `.env.local`.
5. В Project Settings → API скопируйте Project URL и публичный `anon` key в `.env.local`.
6. В Authentication → URL Configuration добавьте локальный адрес `http://localhost:3000` в Redirect URLs. Убедитесь, что вход по Email включён.
7. Перезапустите `npm run dev`, укажите почту на экране входа и откройте одноразовую ссылку из письма.

Секретный `service_role` ключ нельзя помещать в `.env.local`, клиентский код или Git. SQL включает RLS для каждой пользовательской таблицы: пользователь видит и меняет только строки со своим `user_id`.

При наличии переменных окружения приложение автоматически переключается в облачный режим: показывает вход по одноразовой email-ссылке и хранит снимок данных в защищённой RLS строке `settings.app_data`. Последние изменения синхронизируются между устройствами. Нормализованные таблицы также подготовлены для дальнейших интеграций и сложных выборок.

## Где лежат данные

В демо-режиме — в `localStorage` текущего браузера, ключ `apelsin-content-planner-v1`. Удалить их можно через настройки приложения кнопкой восстановления демо-данных либо средствами браузера. Перед очисткой рекомендуется скачать резервную копию JSON.
